## 🚀 How to Run

1. **Install Python (3.9 or higher)**  
   👉 [Download Python](https://www.python.org/downloads/)

2. **Run the application**  
   Open a terminal in the project folder and run:

   ```bash
   # First-time setup
   python setup.py install

   # Start the application
   python main.py
